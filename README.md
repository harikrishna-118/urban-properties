# Urban Properties — React + Vite

A responsive frontend starter with individual JSX and CSS files under `src/components` (no nested component folders). Includes Navbar, six login pages, property category pages, footer pages, and all footer links routed.

## Run
1. Install Node.js LTS
2. Open this folder in VS Code
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed in terminal

## Theme
Navy (#0e2130), warm champagne gold (#d6ad73), white; fonts: Plus Jakarta Sans headings and DM Sans body. Logo: `public/urban-logo.svg`.

## Notes
This is a frontend demo: listings are dummy data; login, registration and loan forms are not connected to a server. Contact details and social profiles are intentionally placeholders. The footer's Projects link was removed as requested. The six Partner With Us links reuse login role routes.
